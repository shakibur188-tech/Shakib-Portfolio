# Md. Shakibur Rahaman — Brand & Performance Marketing Portfolio

A modern, high-converting personal portfolio and interactive CMS built for **Md. Shakibur Rahaman**, Brand & Performance Marketing Strategist and Multi-Industry Growth Specialist.

---

## ?? Key Features

1. **Multi-Industry Growth Architecture**:
   - Covers 7 high-impact sectors: Hospitality & Luxury Hotels, Interior Design, Elite Club Memberships, Education & Study Abroad, Executive Recruiting, Travel Agencies, and D2C E-Commerce.

2. **Continuous 60fps Marketing & Analytics Animated Background**:
   - Interactive HTML5 canvas with real-time marketing nodes, ROAS growth splines, and live attribution telemetry.

3. **Full-Featured Admin CMS Control Center**:
   - 15 granular edit modules for real-time text, statistics, case studies, and image management.
   - Comprehensive **SEO Control Engine** (Meta titles, OpenGraph, Twitter Cards, Keywords, Canonical URLs, and JSON-LD Structured Data).
   - Leads capture, inspection, and 1-click CSV export.
   - Automated content backups and 1-click restore.

4. **Universal Zero-Configuration Portability**:
   - Runs everywhere: Static web hosting (cPanel, Hostinger), Node.js servers, Vercel, Netlify, or local browser.

---

## ?? How to Run Locally

### Option 1: 1-Click Windows Launcher
Double-click `start.bat` to launch the server on `http://localhost:5500`.

### Option 2: Direct Browser
Open `index.html` directly in any browser (Chrome, Edge, Firefox, Safari).

### Option 3: Node.js Server
`ash
npm start
# or: node server.js
`

## ?? File Structure
- `index.html` — Main portfolio single-page application.
- `app.js` — Dynamic content hydration, analytics background canvas, interactive filters, and lead capture.
- `styles.css` — Custom styling, royal sapphire theme, and animations.
- `admin.html` / `admin.js` / `admin.css` — Full Admin CMS & SEO engine.
- `server.js` — Portable Node.js HTTP server and REST API.
- `content.json` — Structured portfolio data and default content.
- `start.bat` — Windows 1-click server runner.
