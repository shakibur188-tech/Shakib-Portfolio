## 🚀 How to Run Locally

### Option 1: 1-Click Windows Launcher
Double-click **start.bat** in the root folder. It starts the local Node.js server and launches your browser at http://localhost:5500.

### Option 2: Command Line (Node.js)
```bash
# Install dependencies
npm install

# Start the production server
npm start
# or: node server.js
```

### Option 3: Expose to Public Internet via Cloudflare Tunnel
```bash
.\cloudflared.exe tunnel --url http://localhost:5500 --protocol http2
```
