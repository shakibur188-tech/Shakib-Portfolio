# Design.md

## Color
- Primary: #70805D (Olive) - main brand color
- Secondary: #2A3B27 (Forest Green) - accent
- Background: #F8F9F6 (Off-white)
- Text: #1C2B1B (Dark Charcoal)

## Font
- Primary: Plus Jakarta Sans (Google Font)
- Weight options: 300 (Light), 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold), 800 (Extra-bold), 900 (Black)

## Typography
- Headings: 
  - H1: 48px (3rem), font-weight 800
  - H2: 36px (2.25rem), font-weight 700
  - H3: 28px (1.75rem), font-weight 600
- Body: 
  - Base: 16px (1rem), font-weight 400
  - Paragraph: 18px (1.125rem), line-height 1.6

## Theme
- Light mode: white background, dark text
- Dark mode: dark background, light text (optional)
- Consistent spacing: 8px grid system (8, 16, 24, 32, 48, 64)
- Shadows: subtle depth with 4-8px blur radius
- Transitions: 0.3s ease-in-out for all interactive elements
- Animations: gentle scroll-triggered fade-ins with 0.5s duration
